# NetPBM Image Color Picker

## Overview

This JavaScript application allows users to extract and pick colors from **NetPBM image formats**, including **PGM (grayscale), PBM (black & white), and PPM (RGB color)**. It provides an interactive way to select pixels and retrieve their color values.

## Features

- **Supports PBM, PGM, and PPM formats**.
- **Outputs in multiple formats**: RGB and HEX.
- **Client-side Processing**: No need for a server; works directly in the browser.
- **User-Friendly Interface**: Simple UI for selecting images and picking colors.
